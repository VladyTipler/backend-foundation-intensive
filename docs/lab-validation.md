# Проверка помощника подготовки

Дата: 19 сентября 2026. Среда: Windows, Node.js 24.13.1, отдельный PostgreSQL 18 в Docker.

## Выполнено

- `npm run lab:test`: **10 passed, 0 failed, 0 skipped** с включённым интеграционным тестом.
- `npm run typecheck` и `npm run build`: успешно.
- `node --check` для всех модулей `scripts/lab/*.mjs`: успешно.
- CLI `--help`: успешно.

## Что проверено

На настоящем одноразовом PostgreSQL: отсутствие схемы выдаёт понятную ошибку; базовый набор содержит 100/1000/300 строк; используются фактические ID, не предполагается начало с 1; есть данные для HAVING; повтор не дублирует данные; изменённые названия и статусы сохраняются, удалённый отклик не восстанавливается.
Проверены откат вставок при ошибке ограничения, набор N+1, личные отклики, nullable-расширение схемы для auth и фактическая вставка 100000 вакансий с повторным запуском без дублей.
Отдельные тесты проверяют атомарный локальный журнал, запрет перезаписи отчёта, отказы для неучебных подключений, скрытие секретов и запрет HTTP-редиректов.

## Граница проверки

Проверки регистрации/сессии/CSRF и экспорта используют локальный тестовый HTTP-сервер. Они проверяют поведение помощника по API-контракту, а не безопасность конкретной реализации ученика. В обычном запуске помощник обращается к настоящему API ученика; тестовая реализация не включается.
Ни auth, ни очередь, ни миграции, ни метрики ученика этим изменением не реализованы. Подготовка Дня 3 завершается только после написания маршрутов auth. Экспорты требуют написанного API, для получения готового CSV нужен работающий worker.
Запуск через двойной щелчок на macOS/Linux в этом прогоне не проверялся. Для всех систем есть одинаковый терминальный вход `npm run lab`.
